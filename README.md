# Cryptogram

Android-форк [Rattlegram](https://github.com/aicodix/rattlegram) — **передача данных через аудиоканал** (data-over-sound) между устройствами через радиоприёмник/передатчик.

## Что сделано

- Исправления интерфейса, шифрования и истории сообщений
- Протокол повторных пакетов для помехоустойчивости
- Шифрование ENC1 (см. ограничения в документации)
- APK собран, 7 тестов пройдено, Lint: 0 ошибок / 36 предупреждений

## Направления на ESP32

- **Bluetooth I2S аудиомост** — двусторонний аудиоблок, модем и шифрование остаются в телефоне
- **ESP32-S3: запись с рации** — автономная запись на SD, детектор сигнала, PTT, цель — 24 часа работы
- **Прототип 0.1.0** — встроенный АЦП, ЦАП PCM5102A, полудуплекс, приоритет приёма (ветка Cryptogram-BLE)

## Статус

Функциональный прототип, стадия стабилизации перед испытаниями и выпуском.
